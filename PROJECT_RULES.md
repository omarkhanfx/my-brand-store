# URBANX Website Project Rules

## Project Goal

Build a premium and professional US e-commerce website for URBANX.

The website serves two main audiences:

1. Customers purchasing URBANX products.
2. TikTok Shop creators considering partnerships with URBANX.

## Development Rules

- Build the website section by section.
- Keep every major homepage section modular.
- Do not modify unrelated sections or files.
- Do not redesign approved sections without permission.
- Do not change global colors or typography without approval.
- Preserve desktop and mobile responsiveness.
- Keep the design clean, modern and premium.
- Avoid a generic dropshipping-store appearance.
- Use reusable components.
- Avoid unnecessary dependencies.
- Never use fake reviews.
- Never use fake sales numbers.
- Never use fake creator statistics.
- Never invent partnership results.
- Keep website performance and loading speed in mind.

## Homepage Structure

1. Announcement Bar
2. Header

11. Why Shop With Us
12. Customer Reviews
13. Social Gallery
14. FAQ
15. Newsletter
16. Footer

## Main Brand Message

Products Creators Love. A Brand Built to Scale.

## Development Workflow

For every section:

1. Build the section.
2. Preview it locally.
3. Review desktop layout.
4. Review mobile layout.
5. Make small requested changes.
6. Approve the section.
7. Commit the approved version to Git.
8. Move to the next section.

## Change Control

For small edits, modify only the requested section.

Example:

"Update only the Hero section. Do not modify Header, Products, Collections or any other approved section."

Never make broad website-wide changes unless specifically requested.
